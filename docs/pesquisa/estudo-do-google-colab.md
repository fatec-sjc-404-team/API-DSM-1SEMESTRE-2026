## O que é o Google Colab

Google Colab é uma ferramente de documentação e prototipagem do Google e com a linguagem em Python, que funciona em nuvem.

É similar ao Google Docs, onde todos com acesso podem editar o arquivo. 

Utiliza bibliotecas do Python nativamente, sem a necessidade de instalação paralela. 

## Principais bibliotecas do Python

Pandas

Matplotlib

Plotly
